# 测试报告

## 1. 执行概况

- **测试对象**：`testing/sut/app.py`
- **测试范围**：16 个接口
- **测试用例数**：手工测试用例 33 条
- **执行方式**：Apifox 批量初筛 + curl 独立复现
- **Apifox 原始结果**：56 个请求、112 条断言；42 个请求被标记失败，39 条断言失败。
- **说明**：Apifox 的 56 是实际 HTTP 请求数，不是正式逻辑用例数；一个逻辑用例可能包含多个请求，例如登出后复用 token、创建评价后访问评价页、支付后复查订单状态；部分请求用于初筛、前置准备或状态复查，不单独列入用例表。
- **自动化测试结果**：共 64 条，`32 passed`、`32 xfailed`、`0 failed`、`0 error`；32 条 xfailed 均关联已确认 SUT 缺陷。执行命令为 `cd testing/自动化 && pytest -q`。xfail 表示测试断言正确业务预期，但当前 SUT 存在对应缺陷。
- **安全专项结果**：覆盖未登录、可预测 token、水平越权、垂直越权、SQL 注入、金额篡改、负数数量下单、商品标题 XSS、paymentId 不匹配回调、伪造支付回调和评价 XSS，已加入 `test_security_special.py`。
- **并发测试结果**：10 个并发请求购买库存为 1 的商品 `id=5` 实测 `success_count=10`、`final_stock=-9`；同一订单并发重复支付和支付 / 回调混合竞争均复现多次接受，关联 BUG-10 / BUG-11 / BUG-14。
- **Legacy 代码审查结果**：共整理 10 条高价值意见，覆盖 `testing/legacy/` 全部 5 个文件，重点包括硬编码凭证、SQL 拼接、并发扣库存、金额精度、异常被吞、资源未释放、敏感信息日志和支付验签缺陷，详见 `testing/代码审查.md`。
- **CI 结果**：`.github/workflows/qa.yml` 已接入 push / pull_request 触发，本地按 workflow 逻辑模拟执行通过：`64` 条测试，`32 passed`、`32 xfailed`、`0 failed`、`0 error`；GitHub Actions 真实执行结果待最终 push 后确认。
- **复现结果**：确认 15 类缺陷，均有真实请求证据。
- **缺陷分布**：S1 11 类，S2 2 类，S3 2 类。
- **当前结论**：不建议上线；认证、权限、金额、支付、XSS、并发和明文密码日志问题均需修复。

## 2. 已执行接口

- 认证：登录、登出、健康检查
- 用户与权限：用户详情、管理端订单
- 商品：列表、详情、创建、上下架
- 订单：创建、详情、我的订单
- 支付：发起支付、支付回调
- 评价：创建评价、评价页 HTML 输出

## 3. 结果分类

### 3.1 正常通过
以下基础功能可用：
- 正确账号登录
- 健康检查
- 商品列表默认查询
- 商品详情正常查询
- 创建商品
- 正常下单链路可创建订单，但金额精度异常，关联 BUG-13
- 库存不足拦截
- 我的订单
- 正常支付
- 创建评价
- 评价页正常渲染

### 3.2 已确认缺陷
共 15 类，详见 `testing/缺陷报告.md`：
- token 可预测且登出后仍有效
- 用户资料水平越权
- 普通用户可访问管理订单
- 商品分页越界
- 商品非法 ID 返回 500
- 商品 keyword SQL 注入
- 商品状态修改越权
- 下单业务校验缺失
- 订单金额浮点精度异常
- 订单详情水平越权
- 支付完整性缺失
- 支付回调未验签
- 评价页存储型 XSS
- 并发购买导致超卖
- 登录日志输出明文密码

### 3.3 不计为缺陷的 Apifox 异常
- **query 参数丢失**：商品列表 `pageSize` 和 `keyword` 用例在 Apifox 结果中未能可靠保留查询参数，已改用 curl 复现。
- **HTML 当 JSON 解析**：评价页返回 `text/html`，Apifox 断言按 JSON 解析导致 `JSONError`；该错误不代表接口缺陷。
- **回调有效签名缺失**：文档未给出签名算法，无法构造合法签名回调；仅对伪造回调和无签名行为做结论。

## 4. 未覆盖内容
- UI 自动化
- 有效签名回调
- 支付幂等与事务的更完整回归

## 5. 结论
当前 L0 手工测试、L1 基础接口自动化、安全专项和并发测试已完成。核心问题是认证、越权、金额篡改、订单金额精度、支付状态、XSS 输出、并发超卖和明文密码日志。
