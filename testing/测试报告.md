# 测试报告

## 1. 执行概况

- **测试对象**：`testing/sut/app.py`
- **测试范围**：16 个接口
- **测试用例数**：33 条
- **执行方式**：Apifox 批量初筛 + curl 独立复现
- **Apifox 原始结果**：56 个请求、112 条断言；42 个请求被标记失败，39 条断言失败。
- **说明**：Apifox 的 56 是实际 HTTP 请求数，不是正式逻辑用例数；一个逻辑用例可能包含多个请求，例如登出后复用 token、创建评价后访问评价页、支付后复查订单状态；部分请求用于初筛、前置准备或状态复查，不单独列入用例表。
- **复现结果**：确认 13 类缺陷，均有真实请求证据。
- **缺陷分布**：S1 10 类，S2 1 类，S3 2 类。
- **当前结论**：不建议上线；认证、权限、金额、支付和 XSS 问题均需修复。

## 2. 已执行接口

- 认证：登录、登出、健康检查
- 用户与权限：用户详情、管理端订单
- 商品：列表、详情、创建、上下架
- 订单：创建、详情、我的订单
- 支付：发起支付、支付回调
- 评价：创建评价、评价页 HTML 输出

## 3. 结果分类

### 3.1 正常通过
以下基础功能可用：
- 正确账号登录
- 健康检查
- 商品列表默认查询
- 商品详情正常查询
- 创建商品
- 正常下单链路可创建订单，但金额精度异常，关联 BUG-13
- 库存不足拦截
- 我的订单
- 正常支付
- 创建评价
- 评价页正常渲染

### 3.2 已确认缺陷
共 13 类，详见 `testing/缺陷报告.md`：
- token 可预测且登出后仍有效
- 用户资料水平越权
- 普通用户可访问管理订单
- 商品分页越界
- 商品非法 ID 返回 500
- 商品 keyword SQL 注入
- 商品状态修改越权
- 下单业务校验缺失
- 订单金额浮点精度异常
- 订单详情水平越权
- 支付完整性缺失
- 支付回调未验签
- 评价页存储型 XSS

### 3.3 不计为缺陷的 Apifox 异常
- **query 参数丢失**：商品列表 `pageSize` 和 `keyword` 用例在 Apifox 结果中未能可靠保留查询参数，已改用 curl 复现。
- **HTML 当 JSON 解析**：评价页返回 `text/html`，Apifox 断言按 JSON 解析导致 `JSONError`；该错误不代表接口缺陷。
- **回调有效签名缺失**：文档未给出签名算法，无法构造合法签名回调；仅对伪造回调和无签名行为做结论。
